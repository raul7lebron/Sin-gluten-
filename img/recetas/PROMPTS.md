# Prompts de foto para las 114 recetas de Libre de Trigo

Genera cada imagen con el modelo/herramienta que prefieras (por ejemplo, el generador de imágenes de Artlist o el de Magnetic/Recraft, ambos accesibles desde claude.ai, o cualquier otro). Recomendaciones:

- **Formato de imagen:** JPG, relación de aspecto 3:2 (por ejemplo 1200×800 px). Cuanto más grande, mejor (se puede comprimir después).
- **Nombre de archivo exacto:** coloca cada imagen en `img/recetas/<slug>.jpg` con el nombre exacto de la tabla de abajo. El sitio ya está preparado para detectarlas automáticamente: en cuanto el archivo exista con ese nombre, `npm run prerender` la usará como foto de portada, imagen de Open Graph/Twitter y `image` del schema Recipe de esa receta — sin tocar ningún código.
- **Estilo:** todos los prompts siguen la misma plantilla (luz natural, plano a 45°, sin texto ni logotipos ni personas) para que las 114 fotos se vean coherentes entre sí como una sola colección editorial.
- Una vez tengas los archivos, súbelos a `img/recetas/` en el repositorio (o mándamelos y los subo yo), y ejecuta `npm run prerender` para regenerar el sitio.
